# Studio Relay Projects Page

Salo-inspired `/projects/` rebuild using original placeholder assets and a standalone Astro frontend.

## Run Locally

```bash
npm install
npm run dev
```

Open:

```text
http://127.0.0.1:4321/projects/
```

## Build

```bash
npm run build
```

The static site is generated in `dist/`.

## Scope

- Rebuilt `/projects/` as an Astro page.
- Added 4 project detail placeholder pages.
- Added original SVG mockup assets under `src/assets/projects/`.
- Added sticky header behavior, mobile menu, horizontal carousel, progress bar, smooth scrolling, and button hover glow.
- No Salo brand assets, customer logos, screenshots, or source code are reused.
